FM‑1 GROOVE Installer FM‑1 Groove Studio et brancher ton FM‑1
Vue FM‑1Éditeur
1

Installer l’app sur l’ordinateur

FM‑1 Groove Studio s’ouvre alors dans sa propre fenêtre, comme un logiciel, et marche sans connexion internet. Tes projets et tes sons restent sur cet ordinateur.

Ouvre cette page dans Chrome ou Edge sur ordinateur.
2

Brancher le FM‑1 en USB

Branche le FM‑1 avec un câble USB qui transporte les données (pas un câble de charge seule), allume-le, puis clique sur Connecter. Le navigateur te demande l’accès aux appareils MIDI : accepte.

En attente…
3

Vérifier les touches et les knobs

Appuie sur des touches et tourne des knobs du FM‑1 : chaque message reçu s’affiche ici. Si rien n’arrive, vérifie le câble et choisis l’entrée du FM‑1 dans l’éditeur.

Rien reçu pour l’instant.
4

Caler le clavier du FM‑1

L’assistant te fait appuyer sur la touche de gauche : ensuite les 27 touches du FM‑1 pilotent la vue FM‑1 (pas, pads, notes). Avec le firmware d’origine du FM‑1, les knobs et les boutons n’envoient rien en USB : passe ces étapes. Avec le firmware Groove (étape 5), plus besoin de l’ordinateur : la machine joue toute seule.

5

Groove directement dans le FM‑1 (firmware)

Le firmware Groove met l’app dans le FM‑1 : 8 batteries + 6 pistes mélodiques, les mêmes pages (LIVE, FX LIVE, ARP, SEQ, FX…), sans ordinateur. Essaie-le d’abord dans le simulateur (le vrai firmware, dans le navigateur), puis installe-le.

Pour installer : Chrome ou Edge sur ordinateur, le FM‑1 branché en USB directement sur le PC, ferme cette app (elle occupe le MIDI du FM‑1), puis suis l’installateur. Ne débranche pas pendant l’installation.
Revenir au firmware officiel : M‑UPGRADE de M‑VAVE (m-vave.com/download → PC Software → M‑UPGRADE, et le firmware FM‑1 officiel).
