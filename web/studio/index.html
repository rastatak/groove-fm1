Apprendre les knobs du FM‑1

Messages reçus du FM‑1
—
Branche le FM‑1 en USB et touche chaque commande sur la machine. Avec le firmware d’origine (et Felucca), seules les touches sont envoyées en USB : elles pilotent toute la vue FM‑1 (pas, pads, notes). Les knobs ne transmettent rien : passe-les, ils marcheront avec le firmware Groove.
